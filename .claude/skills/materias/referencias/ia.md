# Datos e inteligencia artificial

## Convenciones
- Se separa lo que la IA hace de lo que no: sin antropomorfizar («el modelo predice», no «piensa»).
- Datos reales con fuente y licencia; si son sintéticos, se dice.

## Metáforas visuales
- Aprendizaje como ajuste de una recta a puntos (error cuadrático que baja).
- Descenso de gradiente: Nexo bajando una colina con niebla, paso a paso.
- Clasificación: separar bloques de dos colores con una línea.

## Errores frecuentes
- Correlación no es causalidad; sobreajuste; datos sesgados → modelo sesgado.

## Verificación
`codigo` para cálculos y entrenamientos pequeños reproducibles (semilla fija); `dato` para cifras de modelos y estudios.
