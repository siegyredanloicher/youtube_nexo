# Materias de Omnia

Lee la referencia de la materia del episodio (el prefijo del ID: MAT, FIS, QUI, PRG, ROB, IA):

| Prefijo | Referencia |
| --- | --- |
| MAT | `referencias/matematicas.md` |
| FIS | `referencias/fisica.md` |
| QUI | `referencias/quimica.md` |
| PRG | `referencias/programacion.md` |
| ROB | `referencias/robotica.md` |
| IA | `referencias/ia.md` |

Convenciones comunes a todas:
- Castellano: coma decimal (3,14), punto o espacio fino para miles (12 500), unidades SI con espacio (5 m, 9,81 m/s²).
  Inglés: punto decimal, coma de miles.
- Símbolos y nombres como en el currículo oficial español (LOMLOE para ESO y Bachillerato; guías docentes habituales en universidad).
- Cuando un tema reaparece en otro curso, Nexo lo dice: «esto lo viste en 1º ESO; ahora vamos más lejos».
- Materia nueva: crea `referencias/<materia>.md` con las mismas secciones (notación, metáforas visuales, errores frecuentes, verificación, progresión por niveles) y añádela a la tabla.
